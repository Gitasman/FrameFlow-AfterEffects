# FrameFlow AE 2.0.2

CEP-панель для визуального переноса и обрезки слоёв в After Effects. Полный исходник, готовая папка расширения и установочные сценарии входят в пакет. Композиция AE остаётся источником данных.

**Целевой диапазон: After Effects 25.x–26.x, CEP 12, Windows / macOS.** Фактическая сборка AE пользователя неизвестна. Это неподписанная сборка для личной установки, не ZXP и не нативный C++-плагин. Реальный запуск в AE и браузерная проверка верстки ещё не выполнены; список выполненных проверок — в `VERIFICATION.json`.

## Что изменилось в 2.0.2

Исправлена регистрация ядра после `$.evalFile`: код явно экспортируется в `$.global.FrameFlowCEP`, и запросы панели обращаются к той же области. Это устраняет воспроизведённую причину `Host handshake/version mismatch`, когда файл исполняется в локальной области функции. Реальный запуск в AE 25.6.4 после исправления ещё нужно подтвердить.

Даже при ошибке загрузки отчёт сохраняет доступные версию AE, build и ОС; показывает ожидаемую/полученную версию ядра и состояние регистрации. Числовой ID скрипта не выдаётся за имя файла. Одно нажатие **Отчёт** открывает и копирует текст. После сбоя связи автоопрос останавливается до **Обновить**; неподтверждённые операции не повторяются.

**Обновление с 2.0.0 / 2.0.1:** закройте AE, распакуйте этот архив в отдельную папку и запустите тот же установщик. Он заменит расширение по прежнему адресу и сохранит предыдущую копию. ID панели и настройки не менялись. В меню остаётся **FrameFlow 2.0**, в отчёте должна быть версия **2.0.2**.

## Быстрая установка

Сначала распакуйте весь ZIP и закройте AE. ScriptUI 1.4 можно оставить как резервный инструмент; установщик её не меняет. Во время проверки не выполняйте операции одновременно из двух панелей.

### Windows

1. Откройте `install/Install-Windows.cmd` двойным щелчком. Node, Git и права администратора не нужны.
2. Установщик копирует `extension` в `%APPDATA%\Adobe\CEP\extensions\com.frameflow.ae` и включает `PlayerDebugMode=1` только для CEP 12 в текущей учётной записи. Этот режим разрешает загрузку неподписанных CEP 12-панелей; это общее поведение Adobe, не разрешение только FrameFlow. Прежние значение и тип настройки сохраняются вместе с резервной копией.
3. Перезапустите AE → **Window → Extensions** либо **Extensions (Legacy) → FrameFlow 2.0**. Панель можно закрепить в рабочем пространстве.

Откат: закройте AE → `install/Restore-Windows.cmd`. Он восстанавливает последнюю успешно установленную резервную копию; проекты и пользовательские настройки панели сохраняются.

### macOS

1. Откройте `install/Install-macOS.command`. Если Finder сообщает, что файл не исполняемый, разово выполните `chmod +x` для этого конкретного файла. Если Gatekeeper блокирует его, используйте стандартное Open Anyway для проверенного вами файла; установщик не отключает Gatekeeper и не снимает quarantine автоматически.
2. Расширение устанавливается в `~/Library/Application Support/Adobe/CEP/extensions/com.frameflow.ae`. Неподписанная сборка включает `PlayerDebugMode` для `com.adobe.CSXS.12`, сохраняя прежнее значение и тип.
3. Перезапустите AE → **Window → Extensions (Legacy) → FrameFlow 2.0**. Откат описан в `install/RESTORE_MACOS_RU.md`.

При ручной установке скопируйте содержимое `extension` в указанную папку, соблюдая структуру `CSXS/manifest.xml`, `index.html`, `jsx/host.jsx`. Неподписанной сборке нужен режим разработки CEP 12. Если политика организации запрещает его, нужен подписанный пакет; этот архив не обходит такую политику.

Разрешение AE «Allow Scripts to Write Files and Access Network» для операций со слоями не требуется. Панель не использует сеть, Node в CEP, внешний сервер или телеметрию. На Windows PowerShell запускается с обходом execution policy только в процессе установщика, без изменения сохранённой системной политики.

## Управление

| Действие | Управление |
|---|---|
| Выбрать слой | Щелчок по имени или блоку; Ctrl/Cmd — добавить/снять; Shift — диапазон |
| Перенести | Перетащить блок; стрелки ← / → на кадр; Shift + стрелки на шаг; кнопки рядом с шагом |
| Изменить край | Потянуть край блока либо In / Out по курсору; ключи остаются на своих временах |
| Точный ввод | Кнопка панели справа → In / Out / перенос в кадрах → Применить |
| Split | Выбранные слои должны пересекать курсор и оставлять минимум кадр по обе стороны; кнопка Split или S |
| Поставить курсор | Щелчок/перетаскивание по линейке или свободному месту дорожки; поле времени + Enter |
| Масштаб / панорама | Ползунок, + / −, Ctrl/Cmd + колесо; средняя кнопка / Shift + колесо |
| Привязка | N; Alt отключает на время жеста. Привязка к курсору, краям других слоёв, композиции и рабочей области |
| Отменить жест | Escape; отпускание за пределами панели обрабатывается захватом указателя, потеря фокуса отменяет жест |
| Undo / Redo | Обычный Undo / Redo **в AE**; после этого панель обновляется автоматически либо по R |
| Вся композиция | F |

Горячие клавиши действуют при фокусе в панели. Пока вводите текст, они не перехватывают ввод. Перенос мышью округляется до кадров относительно исходного положения; привязка и точный перенос поддерживают subframes. За пределы композиции можно переместить слой, в пределах допустимого диапазона AE; невидимую часть удобно вернуть точным переносом.

Таймкод — **NDF**. При 23.976 / 29.97 используются номинальные 24 / 30 кадров для подписи и реальная длительность кадра для расчёта. Это не Drop Frame. Поле таймкода принимает `HH:MM:SS:FF`; простое число означает секунды. В режиме «Кадры» число означает кадры от начала композиции. Учитывается Display Start для отображения таймкода; внутренние расчёты идут в composition time.

В области по умолчанию выбраны **выделенные слои**. Пустое выделение не расширяется на композицию. «Вся композиция» влияет на шаговый перенос, режимы ключей и удаление паузы; Trim / Split и точный перенос справа работают с явно выделенными слоями. Край отдельного блока изменяет только этот слой.

### Режимы из 1.4

Меню «Слои целиком» также содержит «Только ключи», «Выделенные ключи» и прежний Time Offset. Для режимов ключей появляются кнопки До − / До + / После − / После +. Ключ на CTI относится к «После». Выделение ключей задаётся в AE; полный таймлайн свойств/редактор кривых в 2.0 не входит.

«Проверить» показывает план **последнего выбранного направления**; изначально это «После +». Такая проверка не меняет сцену. При применении цели проверяются заново. 2.0 использует строгий режим: любая недоступная цель отменяет всю операцию до записи. Коллизии ключей блокируются. «Убрать паузу» сохраняет правила 1.4 и действует независимо от выбранного режима.

### Настройки

Тёмная / светлая / как в AE, системный / Arial / моноширинный шрифт, размер текста, высота и отступ строк от 0, ширина имён, скругление, акцент, контраст, единицы времени и пресеты плотности. Светлая тема затемняет акцент до читаемого контраста. Экспорт и проверяемый импорт JSON включены.

Корректные настройки сохраняются локально после короткой задержки, с подтверждением записи. `0` и `false` сохраняются. Неизвестные или повреждённые данные и изменения из другого окна не перезаписываются; новые значения остаются сессионными и доступны для экспорта. Сброс вида сохраняет шаг, режимы операций и сцену. Настройки 1.4 остаются отдельно; автоматического переноса старых ScriptUI-настроек нет. «Как в AE» считывает тему при открытии настроек/перезапуске панели.

## Безопасность операций и границы

- Пока тянете, меняется только локальный ghost. Запись — после завершения жеста, одной Undo-группой. Изменённые извне композиция, порядок/состав слоёв, границы, блокировки, время и выделение инвалидируют снимок. Повторять действие по старым данным нельзя.
- Один RPC за раз, ограниченные запросы и строгий JSON без `eval`. Повторный идентификатор команды не применяет её второй раз. После таймаута возможен уже выполненный результат: сначала **Обновить**, затем проверьте AE. Автоматического повтора записи нет.
- Move использует нативный `startTime`; ключи не сдвигаются вторично. Trim сохраняет Start, времена/метаданные ключей и противоположный край. Для проверки сложного Source Text требуется CharacterRange; неподдержанные значения блокируют операцию.
- Расширение Trim ограничено исходным медиа. Time Remap / обратный Stretch допускают только укорачивание. Обратные In/Out не поддерживаются. Freeze frame, тишина и Smart Ripple не создаются.
- Split выполнен через нативный Duplicate и изменение краёв. Parent, дочерние слои и Track Matte блокируются до записи. Дублирование меняет индексы последующих слоёв: выражения с жёстко заданными индексами, сторонние зависимости и визуальный результат требуют проверки на вашем проекте.
- Один общий источник precomp изнутри не меняется. Protected Regions, сложные Expressions, Auto-Bezier и Roving не получают обещания неизменной картинки при ретайминге. Сохранение метаданных не доказывает сохранение отрисованного кадра.
- Таймлайн читает метаданные, не сканирует все ключи при опросе. Строки виртуализированы; максимум 2000 слоёв, в операциях действуют лимиты свойств/ключей. Обновление можно отключить. Производительность в реальных больших проектах не измерена.
- При ошибке выполняется попытка восстановления; ошибки восстановления не скрываются. Undo-группа не является транзакцией. Если восстановление не подтверждено, проверьте AE и используйте Undo, не повторяйте операцию вслепую.

## Первый запуск и отчёт

Проверьте на дубликате композиции по `docs/AE_SMOKE_TEST_RU.md`. При проблеме нажмите **Отчёт**: текст откроется и скопируется сразу. В окне появится подтверждение копирования. Просмотрите текст перед отправкой. При блокировке обоих способов остаётся Ctrl/Cmd+C. Экспорт TXT зависит от поддержки скачивания в CEP; копирование доступно как резервный путь. В отчёте есть версия инструмента, фактическая AE/OS и исходная ошибка; отправки куда-либо нет.

При отсутствии панели проверьте фактическую версию AE/CEP, путь, режим загрузки неподписанных панелей и перезапуск AE. Если загрузчик или `evalScript` не отвечает, откройте отчёт, затем нажмите «Обновить» для явной попытки подключения; демо не подменяет подключение. В обычном браузере `PREVIEW.html` открывает явно обозначенный пример интерфейса с вымышленными слоями. Демо не моделирует ключи, Undo и работу AE.

## Разработка

`extension/` готова к копированию без сборки. `src/core.jsxinc` — ядро 1.4 с ограниченными изменениями выбора целей; `src/panel-host.jsxinc` — CEP-адаптер. `node tools/build.cjs` собирает полный `extension/jsx/host.jsx` без unresolved includes. `node tools/check.cjs` выполняет строгий ES3 и локальные тесты. Нужен Acorn 8.17.0 либо доступный встроенный Acorn Node через `--expose-internals`; пользовательскому AE Node не нужен. Внешних runtime-зависимостей нет.

Проверки UI используют минимальную DOM-имитацию; это проверка событий и передачи данных, **не реальный браузер и не визуальная проверка**. Сквозной тест интерфейс → URI RPC → ES3 host → интерфейс также использует имитацию AE. Подробный статус и продолжение — в `docs/STATUS.md`.

Smart Ripple, вложенный ретайминг, миниатюры/волны и полноценный редактор ключей остаются следующими этапами. 2.0 предоставляет монтаж слоёв и сохранённые операции с ключами через AE.

Проверенный ZIP также находится в GitHub в `downloads/FrameFlow_AE_2.0.2.zip`. Это архив для установки, не подписанный ZXP. Команда сопровождающего `python3 tools/package.py` выполняет проверки и создаёт архив; пользователю инструмента Python/Node/Git не нужны.
