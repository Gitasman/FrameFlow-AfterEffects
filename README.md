# FrameFlow AE 2.0

Компактная панель для изменения тайминга слоёв и ключей в After Effects. Один самостоятельный JSX, без CEP, установщика и внешних библиотек в AE.

**Статус:** 1.3 проверена пользователем в AE 25.6.4 / Windows. Новая 2.0 прошла автоматические проверки и готова к тесту в AE; автоматические тесты моделируют хост и не заменяют реальный запуск.

## Скачать и запустить

- [FrameFlow_AE_2.0.jsx](dist/FrameFlow_AE_2.0.jsx) — текущая версия.
- [FrameFlow_AE_1.3.jsx](releases/FrameFlow_AE_1.3.jsx) — предыдущая проверенная версия.

Скачайте JSX и запустите в AE через **File → Scripts → Run Script File…**. Для док-панели сохраните [FrameFlow_AE.jsx](dist/FrameFlow_AE.jsx) в каталоге AE `Scripts/ScriptUI Panels`, перезапустите AE и откройте её через **Window**. Закройте предыдущую панель перед запуском новой версии. Пользователю не нужны Node, Git или терминал.

## Обычный сдвиг

Укажите шаг в кадрах и нажмите −/+ в группе «До курсора» или «После курсора». Ключ на курсоре относится к «После». Целый слой перемещается нативно; у пересекающего курсор меняются ключи нужной стороны и соответствующий In/Out. «Авто» использует выделенные слои, а без выделения — всю композицию. Исходное выделение сохраняется.

«Убрать паузу» закрывает пустой промежуток под курсором. «Детали» сохраняют последний результат и позволяют проверить один из четырёх сдвигов без применения.

## Новое в 2.0: время анимации

**Вставка / удаление времени…** открывает отдельное окно. Начало и длина указаны в кадрах от внутреннего начала композиции; дробные значения допустимы. Можно взять начало от курсора или заполнить интервал из рабочей области.

1. Выберите операцию и интервал.
2. Нажмите «Проверить»: отчёт покажет цели, число сдвигаемых/удаляемых ключей и блокировки.
3. Нажмите «Применить»: сцена проверяется заново, изменение выполняется одной операцией Undo.

**Вставка:** ключи на начале интервала и позже сдвигаются вперёд; следующие слои перемещаются целиком, у пересекающих начало растёт Out.

**Удаление `[A, B)`:** ключи внутри интервала удаляются; ключи с B и позже сдвигаются назад. Границы пересекающих слоёв сжимаются. Ключ на B сохраняется и перемещается в A. Значения и атрибуты оставшихся ключей сохраняются; интерполяция между соседними ключами может измениться.

Длительность композиции, курсор и рабочая область сохраняются. Вставка времени меняет расстояние между ключами и **не создаёт стоп-кадр**. Это операция над таймингом анимации, а не монтаж исходного видеоряда.

Новые операции выполняются целиком. Если затронутая цель недоступна, никакая часть операции не применяется. Старые четыре кнопки сохраняют прежнее поведение с явными пропусками.

### Границы версии 2.0

- Слой целиком внутри удаляемого интервала блокирует удаление: объекты Layer автоматически не удаляются.
- Удаление всех ключей обычного анимируемого свойства блокируется. Маркеры могут быть удалены полностью.
- Частичное изменение видео, аудио и прекомпозиций требует уже настроенного Time Remap. Целые слои с такими источниками могут перемещаться нативно.
- Locked, Protected Regions, неоднородный перенос Roving, неподдержанные специальные свойства и пересекающие границу маркеры с длительностью дают явную блокировку.
- Содержимое прекомпозиций изнутри не редактируется. Внешние выражения и визуальный результат требуют проверки в AE; Auto-Bezier может пересчитываться хостом.

## Проверка новой версии в AE

На копии композиции: слой анимации 0–10 s с ключами 2, 5, 6, 7, 9 s; 24 FPS. Удалите 48 кадров с кадра 120. Ожидаются ключи 2, 5, 7 s, Out=8 s; Undo возвращает все пять ключей. Затем проверьте вставку, несколько выделенных слоёв, отсутствие выделения и заблокированный затронутый слой. При блокировке не должен измениться ни один слой.

## Разработка

Исходники: `src/FFCore.jsxinc`, `src/FFHost.jsxinc`, `src/FFUI.jsxinc`. Сборка объединяет их в самостоятельный JSX с UTF-8 BOM; в AE нет `#include` и зависимостей.

```sh
npm install --ignore-scripts
npm run check
```

Node ≥22 и Acorn 8.17.0 нужны только разработчику и CI. `check` собирает JSX, запускает все тесты и проверяет ES3 синтаксис, включая reserved-identifier AST policy. Проверка синтаксиса не исполняет JSX и не проверяет API AE.
