# Изменения

## 2.0 — время анимации

- Вставка и удаление интервала, дробные кадры, заполнение от курсора/рабочей области.
- Просмотр плана, явные блокировки, применение целиком в одном Undo.
- Полные исходные снимки для восстановления удалённых ключей, метаданных и выделения.
- Привычные сдвиги, пауза, настройки и проверка из «Деталей» сохранены.
- Исходники разделены для сопровождения; сборка по-прежнему выдаёт один JSX.
- Добавлены тесты новых операций и GitHub Actions. Новый код требует пользовательского теста в AE.

## 1.3

Сохранение исходного выделения слоёв после сдвига и восстановления. Проверка четырёх сдвигов без применения в «Деталях».

## 1.2.2

Предварительный пропуск недоступного продления исходного медиа; остальные доступные цели продолжают сдвигаться. Причина пропуска видна в отчёте.

## 1.2

Закрытие пустого промежутка под курсором, гибкие пресеты и сохранение параметров панели.

## 1.1

Единая работа со слоями и ключами; компактный интерфейс без отдельных режимов и ручного обновления.
