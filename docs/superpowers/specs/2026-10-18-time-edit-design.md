# FrameFlow AE 2.0: редактирование времени

Цель: вставлять и удалять интервалы времени в анимации, сохраняя привычные четыре сдвига, точное исходное выделение, выражения и проверяемое восстановление. Версия 1.3 подтверждена пользователем в AE 25.6.4 на Windows.

## Поведение

- Вставка в момент A на D секунд сдвигает ключи с t >= A на D. Слои после A перемещаются целиком, у пересекающих A увеличивается Out.
- Удаление [A,B) удаляет находящиеся внутри ключи и переносит ключи с t >= B на -(B-A). Границы пересекающих слоёв сжимаются по отображению t < A → t; A <= t < B → A; t >= B → t-(B-A). Start пересекающего слоя сохраняется. Целые слои после B сдвигаются нативно.
- Операции работают в текущей области Авто / Все / Выделенные. Длительность композиции, курсор и рабочая область сохраняются. Вставка меняет расстояние между ключами, не создаёт стоп-кадр; интерполяция между соседними ключами может измениться.
- Новые операции выполняются целиком. Заблокированная/недоступная затронутая цель блокирует всю операцию до записи. Прежние четыре сдвига сохраняют прежние правила пропусков.
- В 2.0 не удаляются объекты Layer и не создаётся Time Remap. Слой целиком внутри удаляемого интервала блокирует операцию. Удаление всех ключей свойства также блокируется. Видео/аудио и прекомпозиции без уже включённого Time Remap блокируются при частичном редактировании; их целые слои сдвигаются нативно.
- Roving при неоднородном переносе/удалении, Protected Regions и маркеры с длительностью, пересекающие границу изменения, блокируют операцию. Неподдержанные специальные типы сохраняют запрет частичной записи.
- Одна операция Undo; снимки исходных данных остаются полными, проверяются значения, метаданные, оставшиеся ключи, удаление ключей, границы и исходное выделение. Ошибка восстановления не маскируется.

## Интерфейс

Основная панель получает одну кнопку «Вставка / удаление времени…». Окно: операция, начальный кадр, длина в кадрах, «От курсора», «Рабочая область», «Проверить», «Применить», «Закрыть», копируемый отчёт. Начальные значения — курсор и основной шаг. Дробные кадры допустимы. Изменение полей отменяет предыдущую проверку; применение создаёт новый план и снова проверяет сцену. Настройки существующей панели совместимы с 1.x.

## Архитектура и хранение

Нативный ScriptUI / ES3. Исходники FFCore, FFHost, FFUI разделены для сопровождения, сборка выпускает один самостоятельный JSX без include/runtime-зависимостей. Тесты Node используют моделируемый AE; Acorn 8.17.0 проверяет полный ES3-профиль с дополнительной AST-политикой reserved identifiers. Реальный AE и его внешний вид проверяет пользователь.

Целевой репозиторий: Gitasman/FrameFlow-AfterEffects. Сохраняются существующие файлы и история; изменения в отдельной ветке и PR. В репозиторий входят только исходники FrameFlow, сборка, тесты и документация продукта. Контрольные локальные исследования и сторонние прикреплённые материалы не входят в пакет.

## После 2.0

2.0.x — исправления по тестам в AE. 2.1 — поддержка удаления целых слоёв и полностью опустошаемых свойств после отдельной проработки восстановления. Далее — явные операции Time Remap/стоп-кадра и только затем работа с содержимым прекомпозиций.
