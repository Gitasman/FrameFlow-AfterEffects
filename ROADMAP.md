# План развития FrameFlow AE

Обновлён по сохранённым рабочим этапам и результатам тестирования пользователя. Полный первоначальный план не восстановлен; при его появлении задачи можно согласовать с ним.

| Этап | Содержание | Статус |
|---|---|---|
| 1.1 | Единый сдвиг слоёв и ключей, компактная панель | Проверено пользователем |
| 1.2 | Закрытие пустых пауз, пресеты, сохранение настроек | Проверено пользователем |
| 1.2.2 | Явный пропуск невозможного продления видео | Проверено пользователем |
| 1.3 | Сохранение выделения, проверка сдвига без записи | Проверено пользователем |
| 2.0 | Вставка/удаление интервалов анимации, общее восстановление, исходники и CI на GitHub | Готовится к тесту в AE |
| 2.0.x | Исправления и доводка по реальным тестам | Следом |
| 2.1 | Удаление целых слоёв и переход свойства в статическое состояние с надёжным восстановлением | Следующий функциональный этап |
| 2.2 | Явный стоп-кадр/Time Remap, работа с граничной интерполяцией | После подтверждения 2.1 |
| Позже | Содержимое прекомпозиций, связи и экземпляры, проверка больших проектов | Требует отдельной проработки |

Принцип релизов: одна понятная новая возможность → автоматические проверки → полный JSX → тест пользователя в AE → следующий этап. Переход на CEP/UXP или нативный плагин нужен только при подтверждённом ограничении текущего ScriptUI.
